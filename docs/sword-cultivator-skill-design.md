# 剑修技能设计：御剑远击

> 状态：首版已实现（弧光飞剑、剑修 `keepDistance` 起始移动、弧剑实体与上限诊断、回响同目标延迟命中）。文中数值仍是首轮原型值，需继续通过模拟和试玩调整。本文补充现有技能系统，不改变“动作 + 属性 + 修饰”的组装方式。

## 1. 目标与现状

剑修应通过驭使飞剑在中距离持续攻击，以飞剑轨迹、穿透与布阵形成仙侠辨识度。玩家无需贴身也能发挥起始技能；近身环剑仍是可选的风险型构筑。剑修不是新伤害体系：命中、属性、状态、反应及死亡事件继续走共享结算。

`sword` 风格在最高到达第 3 层解锁，起始动作已改为 `arcSword`（弧光飞剑），移动偏好为 `keepDistance`，推荐距离 78。御剑（环绕半径 12、碰撞半径 8）继续作为可获取动作，必须靠近敌人才能伤害；`swordPierce` 是直线穿透，`swordArray` 是目标处的固定持续区域。场地为 160 × 144 游戏单位，以下距离均为游戏世界单位、时间为秒，伤害沿用现有基础伤害单位，并非角色攻击力百分比。

## 2. 核心体验与边界

- 起始技能“弧光飞剑”：飞剑从角色背侧浮现，向侧后方拉开弧线，再飞向锁定敌人；角色本体不位移。
- 默认保持中距离，敌人贴近时尝试后撤；被包围、靠边或遇到快速敌人仍有风险，不保证安全距离。
- 飞剑可追踪有限移动，但不能跨场无限追敌；目标失效或飞行超时均有确定的结束规则。
- 玩家可以选择穿透直线、固定剑阵或近身环剑；两技能槽限制继续沿用现有系统，不新增专属资源、第三槽或独立职业成长树。
- 以下技能为可装配的动作方向，不代表玩家同时拥有所有技能；获取和替换仍服从现有组件掉落与替换规则。

## 3. 起始动作：弧光飞剑

### 3.1 参数与施放

| 参数 | 原型值 | 说明 |
| --- | ---: | --- |
| 冷却 | 1.2 | 从成功创建飞剑时开始 |
| 基础伤害 | 2 | 命中一次提交一次共享伤害结算 |
| 索敌半径 | 104 | 以施放瞬间角色位置计算 |
| 推荐距离 | 78 | 交由统一移动策略使用 |
| 飞行时间 | 0.55 | 施放到终点的预期时间 |
| 最大寿命 | 0.9 | 包含末段追踪，超时消失 |
| 碰撞半径 | 6 | 与敌人碰撞体半径相加判定 |
| 命中数 | 1 | 首个碰撞目标受击后消失 |
| 最大同时存在 | 3 | 达上限不施放、不消耗冷却 |

冷却就绪且存在范围内存活敌人时，选择最近目标，距离相同时以敌人 ID 升序决胜；无目标不消耗冷却。飞剑以施放时角色指向目标的单位向量 `F` 为前方，垂直向量 `N` 为侧方，起点为角色位置 `P - 8F + 5sN`，`s` 在成功施放之间交替为 +1、-1。角色与目标重合时使用上次有效朝向；没有上次朝向时使用固定向右方向。背侧指相对于目标方向，不依赖角色贴图朝向。

### 3.2 轨迹与命中

飞剑沿三次贝塞尔曲线飞行：起点为上述位置；控制点一为 `P - 18F + 20sN`；控制点二为施放时目标位置减去 `18F` 再加 `12sN`；终点为目标当前位置。前 70% 进度锁定施放时的终点和控制点，后 30% 每帧将终点向目标当前位置移动，累计修正不超过 18 单位；控制点二随终点等量平移。此规则给移动目标一定命中余量，快速移动仍可躲开。每帧沿上一位置到当前位置做线段扫掠碰撞，按线段上最早交点、再按 ID 排序；飞剑可被路径上的其他敌人拦截。轨迹可在场地边界外短暂显示，碰撞仅对场内敌人有效；不把起点夹到边界，以免挤压弧线。

锁定目标死亡或失效时不重新索敌，保留最后有效终点继续飞行；若沿途未命中，到达终点后消失。超出最大寿命同样消失。施放后保存技能计划快照：更换组件只影响新飞剑，已发射飞剑按原计划结算。若同帧目标死亡，以统一实体更新及死亡处理顺序为准，禁止对已死亡目标重复结算。

### 3.3 表现

飞剑由半透明剑影在背后显现，约 0.12 秒加亮并沿弧线加速，剑尖始终朝运动方向；尾迹逐渐淡出，命中时产生短促剑光。伤害只在实际碰撞时发生，尾迹不具备判定。多把剑错侧发射，使用低亮度尾迹和数量上限防止遮挡敌人。伤害数字、属性颜色和状态标识沿用共享表现。首版没有音效系统，也没有独立的“减少特效”开关；尾迹已按低亮度、低密度实现，保留剑体与命中提示。

## 4. 其他剑修动作

| 动作 | 定位与规则 | 原型参数 / 取舍 | 状态 |
| --- | --- | --- | --- |
| 飞剑穿敌 | 朝施放时目标方向直线发射，沿途每个敌人最多命中一次，达到命中数或射程即结束；需要排线，不追踪 | 冷却 2.4、伤害 3、速度 240、射程 120、半径 9、最多 3 目标；推荐距离 70 | 已有动作，保留现值 |
| 剑阵 | 在目标当前位置布置固定区域，周期命中范围内有限敌人；敌人离开后不再受击 | 冷却 8、每次伤害 2、范围半径 36、施放距离 80、持续 5、间隔 0.8、每次最多 4 目标、最多 1 阵；推荐距离 60 | 已有动作，保留现值 |
| 环身御剑 | 环绕角色，接触时伤害；同一柄剑对同一目标遵守命中间隔 | 冷却 3.2、伤害 2、环绕半径 12、碰撞半径 8、持续 7、间隔 0.55、最多 2 剑；推荐距离 12 | 已有动作，作为近身备选 |
| 万剑齐发 | 向锁定目标附近发射 3 柄错时弧剑，单体爆发与覆盖兼顾 | 冷却 3.6；每柄伤害 1，间隔 0.12；索敌 104；每柄最多命中 1 目标；每次施放同一目标最多被 3 柄命中 | 后续候选，需独立实现与平衡 |

万剑齐发以施放时最近目标为主目标；每柄依次选择主目标 30 范围内未被本次选择的最近存活敌人，数量不足时回选主目标；目标失效时该柄沿最后有效终点飞行，不临时重选。每柄沿用弧光飞剑的碰撞与失效规则，剑体及伤害均为真实实体，不能仅绘制三柄却结算一次。此候选不纳入首版验收。

## 5. 属性、修饰与构筑

属性槽仍最多一个，火、冰、雷通过现有命中与共享状态规则结算；剑阵每次脉冲、每柄飞剑各自是一次命中，不额外发明叠层或反应倍率。修饰槽仍最多一个，明确能力契约后才允许装配：

| 组合 | 首版规则 |
| --- | --- |
| 弧光飞剑 + 回响 | 命中后按现有回响规则延迟 0.7 秒对同一目标追加 50% 伤害，不复制飞剑实体；目标已死亡或失效时该次回响自然落空 |
| 弧光飞剑 + 引爆 | 命中时使用现有引爆规则消耗已有状态；冷却倍率沿用现有定义 |
| 弧光飞剑 + 分裂 | 首版不开放；现有分裂要求 `ranged`，新增能力标签前须明确二次效果与追踪规则并测试 |
| 弧光飞剑 + 扩大 / 牵引 | 不兼容；飞剑不是区域动作 |
| 剑阵 + 扩大 / 牵引 | 沿用现有区域动作兼容与结算；扩大影响范围并降低频率，牵引按共享规则处理 |

可试玩构筑：① 冰霜弧光飞剑 + 雷电剑阵，以中距离攻击与固定区域控制配合共享反应；② 飞剑穿敌 + 火焰剑阵，利用排线和群体聚集；③ 环身御剑 + 剑阵，以近身风险换取持续覆盖。实际反应是否触发以现有状态条件和顺序为准，不承诺每次命中都触发。

## 6. 移动、进度与兼容

剑修起始动作已改为弧光飞剑，默认移动偏好改为 `keepDistance`，推荐距离 78。当前移动策略对多个技能的推荐距离取最大值，`approach` 取最小值、`auto` 取两者折中；因此混搭环剑时默认远程策略可能降低环剑收益，玩家可自行切换策略。移动层已有 ±8 的距离容差与回场中心倾向，边界和拥挤场景下不能保证维持 78。

解锁条件保持最高第 3 层。已有保存构筑不静默替换其动作或组件；新建剑修起始构筑使用新动作。切换风格依现有规则重新开始本轮；v5 存档只保存组件 ID，弧光飞剑作为新 ID 直接可用，旧存档里的环身御剑仍然保留，无需版本迁移。环身御剑继续作为可获取动作，避免旧构筑失效。技能描述展示实际射程、冷却、伤害和单目标限制，并说明“弧线追踪有限，可被其他敌人拦截”。

## 7. 接入与性能

新增独立动作契约、参数校验及弧剑实体；通过世界接口创建实体和提交命中，复用共享属性、修饰与反应，不在伤害核心按风格 ID 分支。客户端通过事件和实体位置渲染，视觉插值不得影响碰撞。实体保留来源、计划快照、目标 ID、轨迹、时间及最后有效终点；结束后释放引用。遵守现有全局实体限制：达到本动作或全局上限时拒绝创建、不消耗冷却，并写入诊断，避免表现与结算不一致。固定步进、稳定排序和线段扫掠保证同输入可复现；大时间步也不能穿过敌人而漏判。

## 8. 平衡与验收

基准为现有飞弹（冷却 0.9、伤害 2）及同条件的穿敌、环剑；不可仅按面板 DPS 判断，须在相同敌人、种子、层数和组件条件下比较实际命中率、清怪时间、受伤和生存。初版弧剑单目标理论上限为每秒约 1.67 基础伤害，未计飞行、空放及属性，与飞弹约 2.22 对照；弧线和有限追踪是体验差异，不应同时获得无代价的高覆盖和高伤害。

验收场景：

1. 在 78 距离面对静止敌人，不需接近即可自动施放、沿背侧弧线命中并显示一次伤害；超出 104 不施放。
2. 目标横移时轨迹遵守 18 单位修正上限；快速离开可躲避，途中其他敌人可拦截；大步长下不穿模漏判。
3. 目标死亡、目标重合、场地边缘、无目标、实体满额及飞剑超时均安全结束，不额外扣冷却或产生幽灵伤害。
4. 切换组件后旧剑保持快照；火冰雷、回响及引爆按明确契约结算，同目标不会因视觉尾迹额外受击。
5. 剑修默认保持距离；混搭近战及切换三种移动策略后，距离符合现有决策规则；旧构筑仍可使用环身御剑。
6. 相同种子重复运行结果一致；压力场景实体数受限、无残留，低特效模式仍能辨认剑体及命中。

先实现并验证弧光飞剑与起始移动，使用现有测试框架覆盖轨迹、碰撞、生命周期、组合和迁移，再用模拟工具和实际画面试玩校准。确认首版可读性与生存表现后，再决定是否实现万剑齐发；若弧线占屏过大或命中率过低，优先调整控制点和追踪上限，而非直接叠加伤害。

## 9. 首版实现记录

首版按第 8 节顺序实现弧光飞剑与起始移动；飞剑穿敌、剑阵、环身御剑保持原参数，万剑齐发未实现。

| 落点 | 文件 | 内容 |
| --- | --- | --- |
| 动作数据 | `src/game/skills/content/actions.js` | `arcSword` 参数、`homing` 能力、推荐距离 78 |
| 动作契约 | `src/game/skills/actions/contracts.js` | 参数校验、`life >= flightTime`、射程/冷却/单目标/拦截描述 |
| 施放 | `src/game/skills/actions/arcSword.js` | 索敌、背侧起点、左右交替、计划快照、实体上限诊断 |
| 实体 | `src/game/skills/entities/arcSword.js` | 三次贝塞尔、末段 18 单位修正、子步扫掠、命中/超时清理 |
| 世界接口 | `src/game/skills/world.js` | `sweepEnemies`、弧剑实体上限、最近目标同距离按 ID 决胜 |
| 风格 | `src/game/skills/content/styles.js` | 剑修起始 `arcSword`、移动偏好 `keepDistance` |
| 修饰 | `src/game/skills/modifiers/index.js` | 弧剑回响走同目标延迟命中 |
| 表现 | `client.js` + `tools/build-client.mjs` | 弧剑剑体、淡入与低亮度尾迹、施放剑光 |

实现取舍：

- 进度按 `elapsed / flightTime` 归一化；前 70% 锁定终点，后 30% 每帧把终点向目标当前位置修正，修正量从施放时终点起算并夹在 18 单位内，控制点二同步平移。`life = 0.9` 作为硬上限。
- 每帧沿曲线按参数细分，逐段做线段扫掠；同一段按最早交点、再按敌人 ID 排序。大时间步也不会只检查端点而漏判。
- 左右侧由技能实例的成功施放次数奇偶决定；角色与目标重合时沿用该实例上次有效朝向，没有历史时固定向右。
- 达到 3 柄同时存在时 `cast` 返回失败并只写一次 `arc-sword-limit` 诊断，不启动冷却。全局实体上限仍由 `spawnEntity` 的 `entity-limit` 诊断兜底。
- 回响接入时发现共享延迟命令的外层包装错误；修复后弹体、区域与弧剑的回响都能真正执行，并补充了回归测试。这是首版实现顺带修复的既有缺陷。
- 首版不标记 `ranged`，因此分裂不开放；扩大/牵引需要 `area`，同样不兼容。描述中明确“仅命中首个目标”“可被其他敌人拦截”。

验证：`npm test` 覆盖起点/交替、单次命中、18 单位追踪上限、路径拦截、大步长、目标死亡、实体上限、重合朝向、回响、快照与描述；`npm run sim`、`npm run arena` 和 `npm run preview` 用于后续数值校准。
