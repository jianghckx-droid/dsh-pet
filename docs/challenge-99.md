# 99 层挑战：敌人机制设计草案

> 讨论稿 v0.1 · 2026-11-07。以下是提案，不代表已实现；机制与数值均需模拟验证。

## 1. 设计意图

玩家通过卡牌、核心和属性的组合构筑能力；每层敌人则凭**一条自洽、足以改变战斗方式的强规则**构成挑战。它不需要叠加多个弱词条才能成立。玩家观察规则、调整 build，找到多种应对路径，而不是寻找唯一指定卡。

体验目标：看到敌人做出一件不可忽视的事 → 理解自己为何失败 → 换一种组合验证 → 在自动战斗中看到策略生效。敌人可以强得不讲理，但规则必须讲清楚、稳定执行，并留出对抗空间。

## 2. 与现有项目的关系

现有代码中 `floors.js` 配置 1–15 层，26 秒刷怪、45 秒超时；`arena.js` 是确定性自动战斗，场地 160×144，敌人主要直线追击。README 描述失败后保留 build 并在当前层重试，token 额外刷怪；当前已有甲壳、相位、吞噬等锁。旧设计文档与实现部分不同，具体实现以代码为准。

本提案是对现有层制的**重构方向**，不是给现有 15 层继续附加锁。保留格子伤害、自动战斗、构筑、确定性模拟和侧栏可读性；挑战敌人由独立机制驱动，旧锁可保留在其他模式或作为玩家熟悉的背景规则，默认不额外叠在挑战首领身上。

## 3. 一层如何运作

- 每层一个具名挑战敌人，默认单体；其机制产生的小怪、区域或投射物属于该敌人的规则。每层一条主规则，可以包含同一因果链的触发、效果和弱点，不叠加无关机制。
- 提案沿用自动移动和自动攻击；不要求玩家实时躲避、瞄准或按技能。涉及空间的敌人必须让现有自动走位或可配置的自动策略有可验证的应对方式，不能靠假设玩家手操。
- 首次遭遇前展示一句规则和至少一种应对方向；战斗内显示一个主图标和关键计时/层数；失败后显示触发次数、造成的损失和 build 实际行为。完整信息可在详情查看，不强塞进 160×144 画面。
- 击败本层主体即胜利；角色死亡或挑战计时结束失败。初始建议 60 秒上限，具体时间需随原型校准。失败保留当前进度及构筑，自动重试；提供自动调整建议及手动调整入口，避免无限重试完全相同的无解配置。
- token 压力与挑战机制暂时解耦：不直接给首领战追加随机敌人或强度，工作量不改变挑战的公平性。如何保留工作信号的反馈待讨论。
- 解锁下一层、记录首次通关及最佳结果；奖励优先为图鉴、外观或新的构筑选项，不默认把每层变成永久数值膨胀。旧存档映射和 99 层通关后的循环待定。

## 4. 公平性与难度

1. **强度来自改变规则**：例如把密集攻击转成危险、让伤害延迟兑现、复制玩家攻击；不是单纯加血或普遍免疫。
2. **至少两条不同思路**：例如减少触发频率、改变伤害来源、利用时间窗口、承担代价抢杀。不能只靠某一张卡，也不能依赖未解锁内容。
3. **允许不利，但避免封死**：禁止无提示即死、无限无敌、无限恢复和不可中断的永久控制。反制不必让机制消失，也可以是控制代价或调整节奏。
4. **失败能解释**：记录敌人行为、玩家伤害来源、关键资源变化和超时原因。建议与实际因果对应，不把所有失败都归为缺某张卡。
5. **难度不是线性血量**：前段教识别，中段考取舍，后段考适应与代价；首领基础生命、伤害及时限按可用 build 模拟标定。每 11 层形成一个主题段，第 11 层为阶段考试，但仍拥有自己的主机制。
6. **99 层意味着 99 个不同战斗命题**：可以复用状态机和表现素材，但触发、代价或对策至少有实质区别；不把同机制改数字当新机制。

## 5. 99 层敌人概念目录

以下每行是一个待细化的独立主机制，箭头后是可能的应对方向，非唯一解。名称、阈值、持续时间均待原型验证。尤其涉及召唤物、位置、卡牌的规则，需要先验证现有模拟器是否有相应对象或控制能力。

### 1–11：认识攻击节奏

| 层 | 敌人 | 强机制与可能应对 |
|---|---|---|
| 1 | 蓄势者 | 每隔一段时间蓄力重击；打断或在爆发前击杀。 |
| 2 | 甲壳兽 | 每次命中承伤至多 1 格；高频或持续伤害。 |
| 3 | 反弹镜 | 直接弹丸命中反伤；领域、持续伤害或承受反伤爆发。 |
| 4 | 呼吸者 | 周期性进入短暂无敌；持续输出覆盖窗口或集中爆发。 |
| 5 | 吞伤者 | 短时间连续命中会为其充能反击；低频重击或提高生存。 |
| 6 | 愈合者 | 未受伤一段时间便快速回血；维持伤害或短窗爆发。 |
| 7 | 裂伤者 | 对玩家施加持续伤害，反复接触刷新时长；控制距离或增强恢复。 |
| 8 | 狂奔者 | 冲刺撞击后短暂停顿；控制或利用停顿输出。 |
| 9 | 易怒者 | 每损失一段生命永久加快攻击；保留爆发收尾或提高防御。 |
| 10 | 倒刺者 | 近距离伤害会反击；远程输出或承受反击快速击杀。 |
| 11 | 节拍师 | 只在攻击间歇承受正常伤害；覆盖攻击窗口或低频高伤。 |

### 12–22：伤害的代价

| 层 | 敌人 | 强机制与可能应对 |
|---|---|---|
| 12 | 债主 | 玩家造成的伤害有一部分延迟反噬；分散输出或预留回复。 |
| 13 | 贪食者 | 吞噬附近召唤物恢复生命；限制召唤暴露或改用其他伤害。 |
| 14 | 血税官 | 玩家每次回血使敌人获得护盾；减少回血依赖或快速击穿护盾。 |
| 15 | 盾蚀者 | 周期性将玩家护盾转为自身伤害；减少护盾依赖或在触发前抢杀。 |
| 16 | 灼饮者 | 从自身灼烧中回血；物理爆发或施加灼烧以外的伤害。 |
| 17 | 借力者 | 根据最近一次受到的单次伤害强化下一击；多段伤害或防御其重击。 |
| 18 | 伤口收藏家 | 玩家每次受伤增加敌人的攻击力，短暂不受伤则衰减；控场或抢杀。 |
| 19 | 等价者 | 周期性使双方损失当前生命的一定比例；压缩战斗时间或维持血量。 |
| 20 | 护债人 | 玩家每次刷新冷却都会给敌人叠护盾；减少刷新或穿透持续压制。 |
| 21 | 赌徒 | 敌人随机选择强化攻击或自损，结果提前显示；用稳定生存或高爆发应对。 |
| 22 | 清算官 | 累计玩家的治疗量，达到阈值后释放一次大伤害并清零；减少治疗触发或准备承伤。 |

### 23–33：位置与空间

| 层 | 敌人 | 强机制与可能应对 |
|---|---|---|
| 23 | 引力核 | 周期性拉近玩家；近战生存或远程快速削血。 |
| 24 | 放逐者 | 周期性推远玩家；扩大射程或使用持续区域。 |
| 25 | 领地兽 | 在自己的区域内大幅减伤，离开后失效；位移敌人或等待其追击离开。 |
| 26 | 逐迹者 | 沿玩家近期路径留下危险区；自动移动避开或用生存承受。 |
| 27 | 堵门者 | 周期性在场地生成障碍压缩行动空间；范围输出或快速击破障碍。 |
| 28 | 远眺者 | 离玩家越远伤害越高；近距离构筑或迅速控制。 |
| 29 | 环猎者 | 近距离与远距离都危险，中距离较安全；配置自动距离策略或提高容错。 |
| 30 | 撞墙者 | 被推到边界时对玩家造成冲击；避免过度击退或利用定身。 |
| 31 | 游牧者 | 持续移动并避开伤害区域；追踪弹丸或扩大覆盖范围。 |
| 32 | 换位者 | 定期与玩家交换位置；不依赖固定区域或在交换后快速重建区域。 |
| 33 | 迷宫主 | 定期重排少量障碍并释放穿墙攻击；范围覆盖或高生存。 |

### 34–44：时间与时机

| 层 | 敌人 | 强机制与可能应对 |
|---|---|---|
| 34 | 延迟者 | 受到的伤害延迟结算；提前累积伤害或撑过延迟期。 |
| 35 | 回溯者 | 每隔一段时间恢复到此前生命值，每次恢复量有上限；短窗爆发或持续压制。 |
| 36 | 停表者 | 周期性暂停玩家冷却推进；利用持续伤害或提高生存。 |
| 37 | 快进者 | 定期加速自身全部计时；打断或在加速前集中输出。 |
| 38 | 慢钟 | 将过快的攻击延后到固定节拍结算；提高单次伤害或采用其他来源。 |
| 39 | 预言者 | 标记玩家当前位置，延迟后轰击该处；持续移动或承受打击。 |
| 40 | 倒计时者 | 每隔固定时间施放高伤，可通过累计伤害推迟；持续压制或硬抗后反击。 |
| 41 | 余烬钟 | 每次状态到期时爆发伤害；减少状态数量或利用持续直伤。 |
| 42 | 借时者 | 受到控制时延长其下一次攻击的威力；少控速杀或准备防御。 |
| 43 | 窗口守卫 | 每轮仅在首次受击后短时间内脆弱；连续爆发或稳定高频。 |
| 44 | 时序裁判 | 记录玩家最近攻击间隔，对重复节奏减伤；混合不同周期输出或高单次伤害。 |

### 45–55：数量与目标

| 层 | 敌人 | 强机制与可能应对 |
|---|---|---|
| 45 | 巢母 | 持续产卵，卵成熟后孵化；范围清卵或集中击杀主体。 |
| 46 | 替身师 | 定期制造替身分摊受到的伤害；范围清除或穿透分摊。 |
| 47 | 殉道者 | 每个随从死亡时治疗主体；优先主体或集中击杀随从后爆发。 |
| 48 | 指挥官 | 随从存活时强化其攻击；范围压制或承担压力直击主体。 |
| 49 | 寄生者 | 将自身附着到随从，宿主死亡后脱离并短暂脆弱；清宿主或覆盖脱离窗口。 |
| 50 | 墓园主 | 周期性复活已倒下的随从，复活次数有限；快速清场或直击主体。 |
| 51 | 分裂王 | 首次濒死时分成两个共享总生命的个体；范围输出或逐个击破。 |
| 52 | 连结者 | 将自身受到的部分伤害转给随从；同时伤害多个目标或优先清随从。 |
| 53 | 猎犬主 | 每隔一段时间派出追踪召唤物的猎犬；保护召唤物或换伤害来源。 |
| 54 | 集群核心 | 场上随从越多主体攻击越快；控制数量或快速斩首。 |
| 55 | 幻影剧团 | 周期性产生若干外观相似的假身，只有主体受伤；范围覆盖或使用可识别主体的自动选敌。 |

### 56–66：状态与构筑

| 层 | 敌人 | 强机制与可能应对 |
|---|---|---|
| 56 | 净化者 | 周期性移除自身状态并按移除数量反击；直伤或低频状态配合爆发。 |
| 57 | 夺标者 | 消耗自身标记强化攻击；不依赖标记或快速兑现标记。 |
| 58 | 寒霜炉 | 冻结结束后释放范围伤害；降低冻结频率或准备承伤。 |
| 59 | 火种贼 | 吸收即将触发的灼烧并向玩家发射；爆发直伤或控制触发量。 |
| 60 | 过载体 | 连锁伤害使其累积电荷，满额释放电击；其他来源或快速击杀。 |

| 层 | 敌人 | 强机制与可能应对 |
|---|---|---|

| 69 | 磨损者 | 玩家每受击一次，短暂降低攻击速度；控制接触或使用持续伤害。 |

| 71 | 不屈者 | 首次致死后保留 1 格并短暂无敌；保留持续伤害或撑过窗口。 |
| 72 | 荒疫者 | 场上存在治疗效果时生成危险区域；减少治疗或主动移动。 |
| 73 | 风险猎手 | 玩家生命越低，敌人攻击越快；维持血线或以低血爆发收尾。 |
| 74 | 透支者 | 自损生命换取高伤害，濒死时停止透支；生存等待或提前击杀。 |
| 75 | 饥饿者 | 一段时间未击中玩家就获得移速与攻击，命中后清零；控场速杀或承受周期攻击。 |
| 76 | 契约者 | 持续共享部分玩家受到的伤害，但自身攻击也更强；反伤生存或远程爆发。 |
| 77 | 极限考官 | 周期性限制本次治疗的上限；减少受击或靠护盾与爆发。 |

### 89–99：终局命题

| 层 | 敌人 | 强机制与可能应对 |
|---|---|---|
| 89 | 长夜 | 随时间逐步缩小玩家有效攻击范围，有下限；近战构筑或快速击杀。 |
| 90 | 绝响 | 玩家一次伤害越高，敌人下一次攻击越快；多段或高防御爆发。 |
| 91 | 饱和者 | 同一时间只结算有限次数的伤害，超出次数转为敌人护盾；减少无效命中或提高每次伤害。 |
| 92 | 风暴眼 | 周期性改变安全距离并提前提示；配置自动距离策略或提高容错。 |
| 93 | 不死债 | 敌人受到致死伤害时转成逐渐衰减的护盾，护盾耗尽才死亡；持续输出或生存等待。 |
| 94 | 审判天平 | 定期比较玩家造成与承受的伤害，输出远高于承伤时发起重击；防御重击或控制输出节奏。 |
| 95 | 残存者 | 每失去一段生命就永久关闭一个受到伤害的来源类别，但至少保留一种类别；多样构筑或在关闭前爆发。 |
| 96 | 轮回兽 | 死亡后以剩余时间和有限次数复活，每次生命降低；持续输出或预留收尾时间。 |
| 97 | 缺口 | 持续生成护盾，只有在玩家连续一段时间未造成伤害后才短暂停止；间歇输出策略或高输出击穿。 |
| 98 | 适应者 | 定期大幅抵抗最近造成伤害最多的类型，下一次重新选择；混合伤害或承受抗性强攻。 |

## 6. 首批原型：先验证三个不同命题

建议先实现第 2、12、45 层：甲壳检验单次伤害限制与高频构筑；债主检验强机制的明确代价与结算反馈；巢母检验主体与衍生单位的目标选择。这三层均需支持至少两条可实际获得的通关路线，并与纯数值基线对照。

每层详细规格应包括：触发、对象、数值与上限、持续时间、结算顺序、死亡/超时交互、表现、至少两种对策、失败诊断和确定性测试。第 12 层例如：记录实际造成的伤害而非原始伤害；延迟反噬可否被护盾或减伤抵消必须在实现前固定；不让反噬再次触发自身。

验证：固定种子与 dt，比较高频、爆发、持续伤害、召唤和防御代表 build；记录通关率、时长、伤害来源、机制触发次数及失败原因。检查敌人是否能表现其机制、是否存在两条路线、是否有不可解释的失败；数值结论需实际模拟后给出。

## 7. 实施影响与待定决策

- 战斗引擎需要可复现的敌人行为状态、事件与计时；伤害统一走既有裁决入口，明确延迟伤害、反伤、死亡及同帧事件顺序，防止递归触发。挑战配置与运行状态分离。
- 当前自动走位、召唤物目标规则及 UI 未必支持目录中的空间、选敌和停手命题；需要增加可配置自动策略或重设计这些敌人，不能假定已有能力。大多数目录项也尚无实现或平衡数据。
- 存档需要版本化，定义旧层数、属性、核心和当前 build 的迁移；挑战结果与自动重试状态应可恢复。
- **待一起决定**：① 99 层是替代现有刷层还是独立模式？② 每层单首领还是允许固定杂兵？③ 失败后保留 build 和自动重试的程度？④ 挑战前能否自由调整卡组/自动策略？⑤ 通关奖励偏永久成长还是解锁构筑/收藏？⑥ 是否接受对既有敌人机制重新诠释？

本目录是讨论用的广度草案，不承诺 99 项都已满足差异性和可解性；先冻结整体方向，再逐段淘汰重复项、补全规则和实测。
