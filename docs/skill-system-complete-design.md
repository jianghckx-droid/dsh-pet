# 技能系统完整机制设计

状态：玩法设计稿 v1.1；架构升级阶段 A/B 与部分 C 内容已接入（2026-11）。本文描述目标体验，未实现项见 [技能系统架构设计](skill-architecture.md) 的实现落点与 [多战斗风格技能架构升级策略](combat-style-architecture-upgrade.md) 的实现状态。数值、成长节奏和部分后期规则须通过原型验证。技术实现见 [技能系统架构设计](skill-architecture.md)；早期方案见 [技能系统玩法设计](skill-system-design.md)。两份玩法文档如有差异，以本文为准；实现前应同步架构稿。

## 一、设计目标

宠物在侧栏自动战斗，玩家通过阶段性选择组装技能、观察结果、调整构筑。系统追求技能组合的创造感，但不要求玩家编排指令、理解嵌套或进行实时操作。

**技能 = 动作 + 属性 + 修饰**。不同技能通过目标状态、位置和死亡事件相互影响，形成玩家可理解、但结果随战场变化的连锁。

设计原则：动作单独可用；同一组件的含义尽量一致；反应是公开的世界规则；同一敌人有多种应对方式；升级选择可等待玩家处理；新组件应产生新的选择而不是只有数值增长。

## 二、一局的循环

```text
基础技能出发 → 自动战斗 → 升级产生选择 → 组装技能
      ↑                                      ↓
  新一轮与长期解锁 ← 本轮结算 ← 通过战斗并继续调整构筑
```

宠物自动移动、选敌和施放技能，敌人自动行动。击败敌人获得经验，升级后产生三选一；玩家没有处理时战斗继续，选择进入队列，不自动代选。之后玩家可逐项处理。

同一轮的构筑跨战斗保留。一轮结束重置临时构筑、等级和备用栏，长期保留解锁记录、最高进度和战斗统计。长期解锁节奏及失败后的具体出发入口仍待验证；旧属性、核心、卡牌和敌人锁不作为前提。

## 三、一局内的成长阶段

阶段按已完成的选择次数逐步开放，不要求玩家持续在线。以下是教学顺序，具体等级、经验与奖励频率由测试确定。

| 阶段 | 开放内容 | 玩家学到什么 | 示例 |
|---|---|---|---|
| 0 出发 | 从已解锁的起始动作中选一个，属性和修饰为空 | 一个动作即可战斗 | 例如挥斩、飞弹或守卫 |
| 1 属性 | 首次选择提供火、冰、雷 | 属性改变命中效果 | 飞弹变成火球 |
| 2 修饰 | 开放修饰和其他属性 | 技能行为可改变，也可替换组件 | 火球命中后分裂 |
| 3 第二技能 | 至少完成前三次选择后，候选加入新动作 | 技能可共享战场状态 | 冰霜挥斩配合冲击 |
| 4 构筑成形 | 继续选择、替换和使用备用栏 | 为战术补足覆盖或应对弱点 | 为冰爆流增加远程能力 |
| 5 后期扩展 | 完整版视验证结果开放更多组件及第三技能 | 多个技能形成更丰富的配合 | 三个技能分别铺状态、聚怪和兑现 |

第一版原型最多两个技能；完整版目标最多三个，须先验证侧栏可读性、选择节奏和性能。

## 四、技能组装与替换

每个技能有一个必需动作槽、一个可空属性槽和一个可空修饰槽。动作决定施放方式和基础伤害；属性提供附加效果；修饰改变范围、次数或行为。

三选一可提供新动作、属性或修饰。新动作创建技能；属性和修饰装入兼容技能。存在多个合法位置时由玩家选位置，只有一个位置时可直接装入。选择前应展示完整技能描述、目标槽位和被替换组件。不可装配的候选不得进入当前三选一。

替换属性或修饰时，旧组件进入备用栏。建议初始容量为三个，允许之后装回；只有取出本次装配组件后仍然没有空位，才需要丢弃旧组件，并提前展示后果。动作的替换和移除属于后期待定功能。

技能变更影响之后的新施放；已经发射的弹体和已产生的延迟效果沿用产生时的配置。组件兼容性由清楚的行为能力决定，界面解释不能装配的原因。

## 五、动作：技能怎样发生

| 动作 | 基础行为 | 强项 | 弱项 | 阶段 |
|---|---|---|---|---|
| 挥斩 | 朝近处目标挥出扇形攻击，命中扇区内有限敌人 | 高近距离覆盖，可触发强力命中 | 必须接近敌人，有暴露风险 | 原型 |
| 飞弹 | 向射程内最近敌人发射弹体，接触后命中 | 远程、集中输出 | 有飞行时间，对群能力有限 | 原型 |
| 光环 | 周期性影响宠物周围有限数量的敌人 | 持续处理近身敌人 | 覆盖范围有限 | 原型 |
| 冲击 | 在射程内选定敌人的位置，产生范围强力命中 | 周期性群体爆发、触发碎裂 | 施放较慢 | 原型 |
| 御剑 | 驱使飞剑环绕自身，接触敌人时造成伤害 | 以飞剑护身，可利用走位持续输出 | 覆盖范围有限；同一柄飞剑对同一目标有命中间隔 | 扩展 |
| 飞剑穿敌 | 朝目标方向放出直线飞行的飞剑，沿途命中有限敌人 | 强化直线覆盖与远程穿透 | 需要预判路径；命中数量有限 | 扩展 |
| 剑阵 | 在目标位置布下固定区域，周期性影响范围内敌人 | 把输出转向固定区域控制 | 敌人离开区域后收益下降 | 扩展 |
| 陷阱 | 在敌人可能经过的位置放置陷阱，敌人靠近时触发范围效果 | 预先布置、限制通道 | 需要敌人进入范围；数量和持续时间有限 | 扩展 |
| 突进 | 朝选定敌人移动一段距离，对路径上敌人造成伤害 | 快速接敌、穿越敌群 | 改变站位，有进入危险区域的风险 | 扩展 |
| 召唤 | 产生自动攻击的伙伴 | 多个攻击来源 | 受存续和数量限制 | 扩展 |

目标选取、范围和最大目标数应在描述中可见。挥斩不能变成远程技能：没有近处目标时宠物根据构筑的移动策略接近目标；飞弹倾向保持距离。多个动作混用时由玩家选择「接近」「保持距离」或「自动」，自动按当前已装备动作的射程权重选择距离，不由每个技能抢夺移动控制。突进只在目标可达且落点处于场内时施放；若没有安全落点则等待，安全判断与具体阈值须测试。召唤物的生命、存续时间、重召方式，以及敌人是否攻击召唤物仍待设计。

### 起始战斗方式

初次游玩先提供**挥斩与飞弹**两个起始选择，选中后立即开始；后续通过游玩解锁御剑、陷阱和召唤作为可选起始动作。所有起始动作在无属性、无修饰时必须能独立完成教学战斗；解锁提供不同风格，不提供严格更强的基础数值。后续也可以在同一轮获得其他动作，形成近远搭配。

| 风格 | 起始动作 | 初始策略 | 提供的玩法 |
|---|---|---|---|
| 近战斗士 | 挥斩 | 接近 | 用扇形打击应对近身敌人，承担接敌风险 |
| 远程射手 | 飞弹 | 保持距离 | 通过射程与飞行时间处理目标 |
| 剑修 | 御剑 | 接近 | 驭使飞剑环身护体，凭站位让敌人持续受到剑击 |
| 陷阱师 | 陷阱 | 保持距离 | 引导敌人经过预设位置 |
| 召唤师 | 召唤 | 自动 | 由伙伴持续攻击，自身管理距离 |

起始动作和移动策略可在新一轮出发前修改；战斗中技能仍自动施放。解锁条件暂不设具体数值，要求普通游玩即可逐步取得。

**剑修的风格**：以御剑、剑气和剑阵为视觉意象，飞剑运行时留下简洁剑光；技能名称与特效体现仙侠气质，但属性与状态仍遵循所有角色共用的规则。初始御剑是环身护体；当前原型另有飞剑穿敌（直线穿透）与剑阵（固定区域周期伤害）两种方向，分别强化直线覆盖和站位控制，后续仍可探索聚剑齐发、剑阵布置等动作与修饰；这些扩展需要分别定义适用能力、代价和清晰的攻击边界。

## 六、属性与状态

| 属性 | 基础效果 | 状态或资源 | 阶段 |
|---|---|---|---|
| 火焰 | 命中施加灼烧 | 灼烧定期造成伤害，目标死亡时可传火 | 原型 |
| 冰霜 | 命中施加寒冷 | 寒冷降低移动速度，达到阈值可被强力命中触发碎裂 | 原型 |
| 雷电 | 命中施加充能 | 后续雷电命中可消耗充能并触发导电 | 原型 |
| 生命 | 产生生命能量 | 宠物接触后恢复生命 | 后续 |

灼烧、寒冷、充能都有层数上限和持续时间。重复施加时加层至上限并刷新整体持续时间；灼烧按当前层数周期伤害，寒冷减速存在上限，充能会过期。数值放入平衡配置，玩家不必记忆复杂公式。

不同技能可对同一目标施加相同状态。多来源状态的统计归因需明确并在界面解释，但不应改变实际伤害；生命能量的产生频率、拾取和消失规则待后续设计。

## 七、修饰：技能怎样变化

| 修饰 | 作用 | 适用范围或取舍 | 阶段 |
|---|---|---|---|
| 分裂 | 首次命中后对附近有限目标产生较弱后续命中 | 需要能选定目标；后续命中不再分裂 | 原型 |
| 回响 | 技能生效后延迟触发一次较弱效果 | 延迟效果不再回响 | 原型 |
| 扩大 | 增大影响半径 | 需要范围；延长冷却 | 原型 |
| 牵引 | 命中后将敌人向效果中心拉近 | 需要明确的范围中心 | 原型 |
| 延展 | 增加挥斩的攻击距离或突进路径长度 | 需要近战或路径能力；降低基础伤害 | 扩展 |
| 旋转 | 将挥斩变为环绕自身的一次圆形攻击 | 需要挥斩能力；延长冷却 | 扩展 |
| 穿透 | 弹体或突进沿路径继续影响后续目标 | 需要路径命中能力；有限命中次数 | 扩展 |
| 连携 | 动作结束后延迟进行一次方向相同的弱化动作 | 需要可重复动作；弱化伤害且不再次连携 | 扩展 |
| 聚焦 | 更偏重同一目标 | 减少其他目标覆盖，具体规则待定 | 后续 |
| 引爆 | 消耗目标已有状态造成额外效果 | 可消耗状态和收益待定 | 后续 |

分裂和回响继承属性效果，伤害按比例缩放；原型中状态层数不缩放，并应在描述中说明。范围回响使用第一次施放的效果中心；飞弹回响再次命中原目标，目标已死亡或不可用时失效。每次施放的修饰最多触发一次。

## 八、技能之间的共享反应

| 反应 | 触发 | 结果 | 终止规则 |
|---|---|---|---|
| 传火 | 带灼烧的敌人死亡 | 一部分灼烧传给附近有限数量的敌人 | 新目标之后死亡仍可传火；传播数量和状态层数受限 |
| 导电 | 已充能敌人再次受到雷电命中 | 消耗充能，雷击附近有限目标 | 雷击不施加充能，也不再次触发导电 |
| 碎裂 | 寒冷达到阈值的敌人受到强力命中 | 消耗寒冷，对附近敌人造成范围伤害 | 碎裂伤害不是强力命中，不再触发碎裂 |

一次命中的原则顺序：校验目标 → 扣除伤害 → 施加属性状态 → 检查本次反应和修饰 → 处理死亡及死亡反应 → 处理后续效果。致死命中仍完成本次状态和反应检查，因此火焰致死可传火、雷电致死可导电、强力致死可碎裂。

反应可以由不同技能共同完成：一个技能铺寒冷，另一个技能触发碎裂。连锁安全上限只作为护栏，正常体验不应频繁触及；被截断时应可诊断。

## 九、构筑示例

这些是目标体验而非固定配方；其中召唤和生命尚属后续内容。

| 构筑 | 组合 | 配合 | 弱点 |
|---|---|---|---|
| 野火 | 火焰分裂飞弹 + 火焰扩大光环 | 多处点燃，敌人死亡后向怪群传火 | 孤立强敌难以利用传播 |
| 雷暴 | 雷电回响飞弹 + 雷电召唤 | 多个来源积累和消耗充能 | 敌人分散时导电收益下降 |
| 冰爆 | 冰霜牵引光环 + 强力冲击 | 先聚集减速，再触发碎裂 | 爆发之间有空窗 |
| 霜刃斗士 | 冰霜挥斩 + 牵引光环 | 光环聚怪，挥斩积累寒冷并以强力命中触发碎裂 | 必须进入近距离 |
| 焚天剑修 | 火焰御剑 + 牵引冲击 | 聚怪后让飞剑多次接触并点燃敌人，击败后传火 | 需要维持贴身距离，怕远程火力 |
| 陷阱雷区 | 雷电陷阱 + 雷电飞弹 | 飞弹先铺充能，敌人踩入陷阱后触发导电 | 敌人绕过陷阱时输出不稳定 |
| 剑阵陷阱 | 冰霜牵引陷阱 + 雷电剑阵 | 陷阱减速拉近，剑阵持续触发导电 | 敌人绕过陷阱时输出不稳定；突进与穿透尚未实现 |
| 生命循环 | 生命召唤 + 范围技能 | 多目标攻击产生恢复资源 | 可能输出不足，依赖接触资源 |

玩家更换其中一个组件后仍应有可玩的中间形态，不需要收齐套装才能生效。

## 十、敌人和关卡节奏

| 敌人 | 行为 | 考验 |
|---|---|---|
| 群游者 | 数量多、生命低，成群靠近 | 覆盖和清群 |
| 重甲兽 | 移动慢、生命高 | 集中输出与牵制 |
| 游击者 | 保持距离并移动攻击 | 射程和对移动目标的覆盖 |
| 守护者 | 靠近其他敌人时提供防护 | 优先选敌、范围攻击或改变阵型 |
| 分裂体 | 在特定条件下分裂成弱小单位 | 应对数量突然增加；触发条件待定 |

新敌人先在低压力场景中展示行为，再和已有敌人混合。任何防护或抗性应有可见反馈，并允许多种解法；不设置必须取得某个组件才能通过的硬锁。

## 十一、界面和反馈

构筑面板展示动作、属性、修饰、完整描述、冷却和范围；升级选项预览装入后的结果以及替换后果。状态和反应应能查看简短说明。备用栏满时显示可能丢弃的组件。

战场用清楚的动作、颜色和少量图标表达效果，不能只靠颜色区分。详情统计展示技能有效伤害、状态伤害和反应次数，并说明归因规则；溢出伤害不应表述为有效伤害。可减少重复特效，但不改变模拟结果。

| 阶段 | 范围 | 结束条件 |
|---|---|---|
| A 核心原型 | 挥斩、飞弹、光环、冲击；火冰雷、四种原型修饰、三种反应、两个技能和三种基础敌人 | 近战与远程均能完成教学战斗；玩家能预测技能、看懂反应并创造至少两种不同构筑 |

| C 内容扩展 | 逐项设计并测试御剑、陷阱、突进、召唤，及生命、聚焦、引爆、延展、旋转、穿透、连携和更多敌人 | 每项内容与已有组件产生有意义的新组合；自动移动与站位风险可理解 |
| D 完整版验证 | 评估第三技能、长期解锁与更复杂敌群 | 教学、平衡、性能与存档验证达标 |

## 十三、验证与待决策

验证新玩家能否描述组件作用并找到装配位置；火、冰、雷是否各有可运行路线；是否出现无代价必选修饰。覆盖致死命中、跨多名敌人传火、多来源状态、目标失效及连锁终止。检查积压选择、跨场、失败后状态与长期挂机稳定性。核对预览和实际数值，测量密集敌群下的性能与存档修复。

尚待决策：经验曲线、战斗长度和精确数值；失败后的出发入口和长期解锁；满备用栏的最终交互；召唤和生命能量的详细规则；聚焦的兼容关系；多来源归因；第三技能开放条件。动作替换和引爆已进入当前原型，但仍需试玩调整具体规则。这些项目应依据测试决定，不应将当前代码的偶然行为视为最终规则。

## 十四、当前实现范围（2026-11）

本节只记录代码现状，避免把目标设计误读为已实现：

- **动作**：挥斩、飞弹、光环、冲击、御剑、飞剑穿敌、剑阵、陷阱；共 8 个。飞剑穿敌是直线穿透实体，剑阵是固定区域周期伤害；二者与挥斩、御剑共同构成剑修的多种攻击形态。
- **属性 / 状态**：火焰、冰霜、雷电；灼烧、寒冷、充能。
- **修饰**：分裂、回响、扩大、牵引、引爆。引爆会消耗目标全部状态并在目标处造成按层数缩放的范围伤害，冷却 ×1.2，同一施放只触发一次。
- **共享反应**：传火、导电、碎裂。传火可以跨死亡连续传播，但有 `maxChain = 4` 的安全上限；上限只作为护栏，正常战斗应先由目标数、层数和距离自然终止。
- **风格与移动**：远程射手、近战斗士、剑修、陷阱师；接近 / 保持距离 / 自动三种策略；动作替换在两技能槽已满时开放，替换会保留技能实例 ID、冷却和兼容组件，旧动作与不兼容组件需要备用栏空间，空间不足时拒绝替换并提示。
- **存档**：`dsh.pet.v5`；v4 构筑与进度迁移，v3 只迁移战绩。存档保存风格、移动策略、构筑、层数、等级经验和待选升级；不保存战斗中实体。
- **未实现**：召唤、突进、生命属性、聚焦、多修饰同时装配、第三技能、完整危险评估的位移落点。

验证入口：`npm test`、`npm run build:check`、`npm run sim`、`npm run arena`、`npm run synergy`、`npm run preview`。跨技能配合的结构性观察使用 `synergy-report`，它不能替代真实试玩对可理解性和平衡的判断。
